# 二、命令与账号池

> 返回 [SKILL.md](../SKILL.md)

前缀 `雀魂` 或 `qh`。

| 命令 | SV | 权限 |
|------|----|------|
| `绑定` / `切换` / `删除uid` | 雀魂用户绑定 | 用户 |
| `搜索` | 同上 | 用户 |
| `查询`（可带 三/四） | 雀魂用户信息查询 | 用户 |
| `帮助` | 雀魂帮助 | 用户 |
| `算符` | 雀魂算符小游戏 | 用户 |
| `牌谱Review` | 雀魂牌谱Review | 用户 |
| `场况` / `牌谱详情` | 同上 | 用户 |
| `登陆国服` / `添加账号` | 雀魂账号池 | pm=0 |
| `登录日服` / `登录美服` | 雀魂Yostar登陆 | pm=0 |
| `推送启动` / `重启服务` / `检查服务` | 雀魂推送服务 | pm=0 |
| `订阅` / `取消订阅` | 雀魂订阅推送 | 用户 |
| `订阅雀魂推送` | 雀魂推送订阅 | pm=0 |
| `好友排行榜` | 雀魂好友排行榜 | 用户 |
| `好友总览` / `好友申请` / `同意好友申请` | 雀魂好友管理 | pm=0 |

国服登录格式：`雀魂登陆国服 用户名, 密码`（见 `__init__.py` 的 `EXSAMPLE`）。
日/美服：邮箱验证码流程。

账号池写入 `MajsUser`。`manager.get_all_conn()` 为空时 review 直接失败。
