## 账号池

账号写在 `MajsUser`，运行时是 `majsoul.manager`，每个号一个 `MajsoulConnection`，各自登录、各自重连。

- Core 启动时 `on_core_start` 在后台调 `manager.start()`，相当于客户端用存下的 token 自动登录。
- `推送启动`：把没在线的号都登录一遍，被顶号后的「自动重登一次」机会也重新算。一个号失败不影响别的号。
- `重启服务`：关掉全部连接，从数据库重新读账号再登录。
- `检查服务`：列出每个号的状态（`ConnState`）和最后一次失败原因，不发请求。
- `登陆国服` / `登录日服`：`manager.add_account` 先关掉同一个号的旧会话再登录，否则新旧两边会互相顶号。
- `订阅`、`牌谱Review`、好友命令、观战定时任务只用 `manager.get_conn()` 拿在线的号，**不触发登录**。
  账号掉线后只有上面三个管理命令会重新登录，避免用失效凭证反复登录。
